# 参考网站实地观察记录

- 参考网站：[Julia Moresco](https://juliamoresco.com.br/)
- 观察日期：2026 年 11 月 7 日，Asia/Shanghai。
- 观察方式：本次会话通过原生 CUA 操作用户实际运行的 Chrome，访问线上首页并点击交互对象。
- 证据形式：各观察状态的截图已在会话中展示；没有保存本地截图文件。本记录整理这些已观察到的界面状态和操作结果。

## 首页与内容入口

首页以立体室内场景承载作品内容，物件是可发现、可点击的入口。项目书籍与场景本身组成访问路径，而不是仅作为文字页面的背景插图。

观察中点击了与 loyalty case 对应的项目书籍。点击后，界面进入展开的书本阅读状态，项目内容成为主要阅读对象。

## 书本阅读

在该项目的书本阅读界面点击下一页后，确认第二页出现图表与文字内容。随后关闭书本，返回房间场景。

此次确认的是「场景选书 → 打开阅读 → 下一页 → 关闭回到场景」这一条完整交互路径。没有录制视频，也没有测量逐帧动画、过渡时长或缓动曲线，因此本记录不对这些细节作精确断言。

## 提示与目录

- 启用 **HINTS** 后，场景物件出现统一的金色提示着色，帮助访客发现可探索内容。
- 打开 **MENU** 后，右侧出现深色抽屉式菜单；其中可见内容导航和语言选择入口。

这两种入口提供了不同的查找方式：在场景中通过提示寻找物件，或通过菜单直接选择内容。

## 本项目采用的参考方向

- 以温暖的个人书房作为主页主体，让真实个人信息与项目对应到房间物件。
- 项目以书籍阅读呈现，提供明确的前后翻页和返回房间入口。
- 提供可切换的物件提示和独立内容目录，降低探索门槛。
- 本项目的中英文内容沿用本人已有资料，房间物件和项目视觉自行制作；不使用参考作者的个人经历或作品材料作为本人内容。

## 尚未验证的部分

本次没有验证参考网站的移动端表现，也没有验证灯具的具体交互行为。截图只能证明所展示的稳定界面状态，不能证明未观察到的动画细节、设备兼容性或其他物件行为。

## Awwwards 设计思路复核

本轮同时查看了 [Awwwards 上的 Julia Moresco Portfolio 条目](https://www.awwwards.com/sites/julia-moresco-portfolio)。该条目记录为 2026 年 10 月 27 日的 Nominee，介绍强调作者的真实办公室以及物件与内容的对应关系：书架承载案例、地球仪承载旅行、电话承载联系，猫咪以对话介绍作者。展示元素包括 Pink telephone、About、Case study、Playful Interactions、Zuko chat 和 Creative navigation；分类标签包含 Unusual Navigation、3D、Microinteractions 与 Project Page。

这些信息支持当前改版的主要方向：房间承担内容导航，项目通过书册展开，物件选择与内容有关联，同时保留直接阅读的目录。暖色与三维造型服务于这条访问路径，技术标签并不要求本项目改用 React 或 TypeScript。

原站公开的作品集设计说明还提到：房间中的物件来自作者实际生活；快捷菜单服务于赶时间的访客；案例页面按叙事选择组件；手机端通过扩大触控区域和清晰文字保持可用性。它们说明物件探索、内容表达与可读性需要一起成立。

本项目的房间是围绕董俊叶既有项目和经历设计的原创概念书房，并未声称复原本人实际住所或拥有某件实物。项目书、实习档案夹、学习笔记和联系信封分别承载已有真实资料；作者的宠物、旅行和个人藏品不会作为董俊叶的经历使用。

据此，本轮在现有改版上做有限完善：增加八个物件入口的探索进度与简短提示，改善手机端关键文字的可读性，并为不同项目设置与其方法相符的章节标题和流程说明。储能监测、Agent 分工、Django 业务模型、实时行情链路、行为分析和 LaTeX 模板使用各自的表达，内容仍限于仓库中已有事实。这些调整延续当前房间和书册结构，同时让探索反馈与项目叙事更清楚。

Awwwards 展示素材与上述说明用于理解设计；本项目不复制其模型、代码或作者的个人材料。该条目的存在也不代表本项目获得任何奖项。
