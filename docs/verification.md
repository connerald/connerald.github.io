日期：2026-11-07（Asia/Shanghai）。实现仍为 GitHub Pages 根目录静态站，无构建步骤或运行时 CDN。

## 实际浏览器与视觉检查

参考站通过用户正在运行的 Chrome 原生界面实际访问，操作书册、翻页、关闭、HINTS 和 MENU，具体结果见 [参考观察记录](reference-observations.md)。新主页也在用户 Chrome 中实际展示并截图，随后使用独立 Chrome 测试配置继续检查，避免与用户的日常标签页操作冲突。

检查了 1440×900 桌面、1200×630 短屏、700×740 平板边界、390×844 手机、320×740 窄屏。最终八个入口均在画面内；常用手机与桌面无横向溢出。修正了欢迎标题与项目索引本的遮挡、手机正文宽度、书册垂直居中和翻页背面文字。

## 功能检查

在桌面与手机分别执行交互检查：

- 八个物件入口和全部七个项目，项目目录与物件使用相同路由；四个既有源码链接保留。
- AnchorCell 两个跨页、两段实习分页、前后翻页、目录切换、关闭至书房、浏览器返回重新打开项目。
- 直接打开 `?lang=en#project/anchorcell`；阅读器内切换语言，同步标题及分享元信息。
- 关闭后恢复可见入口焦点；使用实际 Escape 键关闭；原生 dialog 负责模态焦点约束。
- 复制邮箱提示位于阅读器内部；台灯键盘按钮和场景灯具共用状态；探索提示正常切换。
- 桌面第二跨页切换到手机后，从第一章开始纵向阅读全文。

## 故障与可访问性检查

- 禁用 WebGL 上下文创建：保留原创场景 poster 和八个 HTML 热点，英文项目深链接仍可打开。
- 运行中主动丢失 WebGL 上下文：自动释放画布并回退到 poster。
- 阻止访问 localStorage：页面正常初始化，URL 语言与阅读器正常工作。
- 关闭 JavaScript：完整中文 HTML 资料保持可读，包含七个项目、两段实习、教育、技术与联系方式。
- 模拟 `prefers-reduced-motion: reduce`：书册动画为 `none`，内容可正常访问。
- 正常加载：本地请求无 4xx/5xx、无未捕获 JavaScript 异常；三个源码模块通过 `node --check`，`git diff --check` 通过。

## 验证范围

上述结果针对本机 Chrome。没有将 Safari、Firefox 或实体手机测试描述为已完成；移动端检查使用 Chrome 视口模拟。参考站的录像、精确动画时序及移动端效果不在本次已确认的观察证据中。

## 2026-11-07：Awwwards 对照与闪烁修复

已在用户 Chrome 中阅读 [Awwwards 项目介绍](https://www.awwwards.com/sites/julia-moresco-portfolio)。设计重点是与内容有对应关系的物件导航；本项目沿用原创概念书房、案例书册和快捷目录，并补充八个入口的探索反馈、项目各自的说明及更清晰的手机文字。

### 闪烁的复现与处理

1. **悬停反馈循环，已实际复现。** 在 1440×900 Chrome 中，将鼠标移动到项目热点中心下方 21px，保持不动 2.2 秒。三个精选项目分别出现 77、73、77 次进入／离开事件。物件上浮使绑定其动态位置的热点移出鼠标，取消悬停后又移回，形成循环。现改用静止构图投影热点，鼠标视差统一监听整个房间；同样条件下均为一次进入、零次离开。
2. **加载版式闪现，已实际复现。** 延迟入口模块 1 秒，旧实现显示静态文档后切换为房间。现在立即显示原创 poster；入口模块失败或启动超时则恢复完整 HTML。无 JavaScript 时仍直接显示文档。
3. **书柜深度冲突。** 静态检查确认共享竖板和同层横板存在重复共面表面，已分别合并为单一构件，避免镜头变化时发生深度竞争。
4. **翻页跳变。** 保留动画期间尚未被翻页覆盖的旧固定页，锁定一次翻页，统一清理临时图层；快速反向输入、翻页中关闭和减少动态效果已纳入回归。

### 可重复的浏览器回归

测试文件：[tests/browser-regression.mjs](../tests/browser-regression.mjs)。使用 Node 22+ 内置 fetch/WebSocket，连接独立 Chrome 调试配置和本地静态服务器，不需要安装 npm 依赖。启动命令见文件开头；执行：

```sh
node tests/browser-regression.mjs
```

七组浏览器回归全部通过，无未捕获脚本异常：八个热点底边悬停、真实点击与 Escape、延迟启动、入口模块失败、固定页与反向输入、翻页中关闭、减少动态效果。测试创建并关闭独立页面，不复用用户现有标签页。

手机中英文额外检查了 390×844 与 320×740，放大关键文字后仍保持八个内容入口可用；较矮的英文手机视口允许页面纵向滚动以留足阅读空间。截图、翻页 GIF、分享封面与后备 poster 均已更新。
