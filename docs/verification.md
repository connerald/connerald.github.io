## 修复清单

- 首页主入口进入项目目录；删除重复身份介绍、装饰性页脚和探索计数，保留访问反馈与探索提示。
- 普通项目保留一个跨页，AnchorCell 两个；技术标签、时间、角色、评测数字各呈现一次。学习和联系页移除重复宣言。
- 桌面双页条件统一为宽度 ≥1024px 且高度 ≥720px；其余连续阅读，隐藏分页控件。
- 以章节和页叶记录阅读位置；切换语言、调整窗口和目录往返后保留位置。
- 修复内部书页滚动不冒泡造成的位置缓存失效，以及目录打开期间改变断点后恢复旧布局。
- 最后一个连续章节至少占满阅读视口，避免短章节无法对齐顶部并被误判为上一章。
- 翻页副本继承旧页滚动位置；保留单次翻页锁与临时图层清理。
- 房间返回焦点与目录切换焦点分别维护；三维物件直接点击也绑定当前热点作为返回入口。
- 中文、英文和辅助名称统一切换；打印文档从同一内容源完整生成，避免英文打印时部分段落仍为中文。
- 合并多轮 CSS 覆盖，保留静止投影热点；提示文字按场景边界调整，主要交互目标至少 44×44px。
- 场景继续按需渲染，后台及弹窗期间暂停；捕获前同步渲染，移除常驻绘图缓冲保留。重复释放与事件清理已补全。

## 自动回归

实际执行：

```sh
CHROME_DEBUG_URL=http://127.0.0.1:9224 node tests/browser-regression.mjs
```

**25/25 组通过，无未捕获浏览器异常。** 最终扩充视口矩阵后，两组受影响的响应式检查再次通过。脚本使用隔离 Chrome 配置并自动关闭自己创建的页面。

- 原有七组：八个热点底边悬停、真实点击与 Escape、延迟启动、入口模块失败、固定页及快速反向输入、翻页中关闭、减少动画。
- 中英文各检查七个项目、五个目录入口和三个历史别名；验证语言 URL 优先级、前进后退和无效路由处理。
- 双语检查 320×740、390×844、700×740、701×740、834×1112、1023×768、1024×768、1024×719、1024×720、1440×900、1200×630、844×390、720×450。
- 720×450 模拟 1440×900 在 200% 缩放下的有效布局视口；没有将它描述为浏览器实际缩放操作。
- 检查标题、长文本、页面和阅读器横向溢出；连续阅读顺序与页码隐藏；语言/断点切换保章；目录打开期间双向跨断点；右叶滚动后调整窗口。
- 检查目录焦点链、Tab、Escape、方向键及复制邮箱按钮存在；没有通过测试改写用户剪贴板。
- 检查英文打印、localStorage 受限、WebGL 禁用与上下文丢失、无 JavaScript 的完整文档。
- 所有自有 JavaScript 模块语法检查及 `git diff --check` 通过；最终预览导出记录本地资源响应及浏览器异常。

## 加载与性能记录

[原版采样](previews/before/measurements.json)与[新版采样](previews/measurements.json)包含本机 localhost 的加载事件时间、资源数和 requestAnimationFrame 间隔。场景与内容使用本地资源，后备图体积较原版减小。

这些是单机采样，加载事件不等于 WebGL 首次可交互；requestAnimationFrame 间隔只说明测试浏览器调度，不代表场景渲染帧率。没有据此声称真实移动设备帧率或公网加载速度提升。
